## BUG描述
- 文件传输历史功能：
  - 服务器重启后，所有历史记录表现为不可下载，会提示文件不存在。但是文件仍在服务器。
  - 文件列表中的“删除”按钮无法真正删除记录。
  - 文件记录未保存在发送方一侧。
  - 接收方离线时的文件消息直接丢弃。
## 后续工作注意事项
- UI是第二位的，功能是第一位的。功能可以参考ClientHandler.java中的“指令”思路。
- 完成功能后，也请完成相应的UI。
- 单个源文件不要太长。
- 务必使用多线程、独立socket！保证Client的消息监听线程在任何情况下都无需暂停。
